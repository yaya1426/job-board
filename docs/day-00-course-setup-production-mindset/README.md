# Day (0) Course Setup & Production Mindset | إعداد الكورس وعقلية الإنتاج

## Goal

Set expectations, product context, and engineering mindset before implementation begins. You should understand what you will build, how you will learn, and why the course ships a small production-realistic step from Day 1.

## About these docs

These files are **reference guides** committed alongside the codebase. Use them while exploring the repository—they document reasoning, architecture, implementation steps, and verification aligned with what is actually in the repo.

## Audience and prerequisites

This day is for developers who know the basics of HTML, CSS, JavaScript, React, Git, and command-line usage and want to move from following isolated tutorials to building and operating a complete product.

You do not need prior experience with Next.js production deployments, MongoDB, authentication, file storage, or AI APIs. Those topics are introduced incrementally when the product needs them.

## Day 0 narrative arc

The day moves from your goal to the course's working method:

1. Define the difference between completing tutorials and becoming a market-ready engineer.
2. Replace the vague phrase "production ready" with practical, repeatable engineering habits.
3. Explain why Next.js is a good fit for this product while acknowledging its tradeoffs.
4. Explain how spiral learning and frequent shipping make those habits visible.
5. Introduce `wazifa.app` as the product through which every concept will be practiced.

Day 0 previews the destination without teaching implementation. You finish with a clear mental map and are ready to create and deploy the first version immediately.

## End state checklist

By the end of Day 0, you can:

- Explain "market-ready" without treating it as a job guarantee.
- Describe production readiness as a spectrum rather than perfection.
- Explain why Next.js fits this course and when another architecture could be better.
- Name the course loop: build a vertical slice, review, verify, deploy, and revisit.
- Describe the candidate and admin journeys in `wazifa.app`.
- Explain why the public app and admin dashboard begin as one modular monolith.
- Name the major technologies as a roadmap, without expecting to know them yet.
- State that Day 1 begins with a real deployment, not weeks of local-only setup.
